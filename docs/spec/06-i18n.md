# Languages

Rules of `src/i18n.js`, `src/locales/` and the text of the screen.

## Languages

- English (`en`), the fallback.
- Español (`es`), the source wording.

## Rules

- **I18N-1** The language is the stored choice under `pwa-nexus.lang` when it is supported,
  else the first supported base language of the phone, else `en`. **Automatic** removes the
  choice.
- **I18N-2** Each text that the screen shows is a key of `src/locales/`. Each catalog has the keys
  of `es.js`, with the same placeholders and the same plural forms. `index.html` holds no text of
  its own: an element gets its text from `data-i18n`, an attribute from `data-i18n-attr`.
- **I18N-3** A placeholder `{name}` takes its parameter as typed. A plural entry is
  `{ one, other }`, chosen by `Intl.PluralRules` from the parameter `count`.
- **I18N-4** A missing key shows the `en` text, then the key itself.
- **I18N-5** The manifest takes the name and the description of the language of the screen
  (SW-13).
- **I18N-6** A new language is a catalog in `src/locales/`, its import and its name in
  `src/i18n.js`, its alias in the import map and its file in `SHELL`.
